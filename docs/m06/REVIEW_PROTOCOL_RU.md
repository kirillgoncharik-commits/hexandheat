# M06 — художественная и device приёмка

Открыть существующий review и проверить `review-manifest.json`: version/source/media SHA. В игре Settings → M06 или `?witch=m06`; default сохраняет прежний renderer. Сравнение `/compare.html`, PNG cadence `/media.html`. Ставки только sample, реальные средства отсутствуют.

PO/reviewer отдельно оценивает IDLE, SMALL_WIN и mobile layout: узнаваемость одного взрослого персонажа, читаемость взгляда/мимики, последовательность корпус→плечо→локоть→кисть, цельность плеч/локтей/пальцев, ткань/волосы, self-loop/переход, отсутствие двойного лица/мерцания и перекрытия поля. Сначала6/8/12 FPS без fade, затем короткий fade. Рекомендуемая пара6/12 — кандидат, не обязательное художественное решение.

В `/media.html` можно ставить паузу и scrub на подготовку0.42, раскрытие1.45, акцент1.95, затухание2.55, возврат3.25, seam0/4. Новый IDLE — небольшой перенос внимания/дыхание/моргание, без победного жеста. Поворот взгляда подсказан наклоном головы: независимого iris tracking нет. Экспорт preview сохраняет4s немого WebM из PNG; это запись исходного клипа, не доказательство30 уникальных поз/с или настоящего мобильного decode.

Для реального игрового размера:360×640,390×844,430×932,844×390,480×320 и desktop. `?qa=1` показывает лицо/ячейку/hero/scroll и текущий media fallback. `/m06-qa.html` проверяет landmarks каждого кадра; `/controls-qa.html?m06=1` выполняет48 сценариев F01–F12 через реальные кнопки. Смена state в художественном стенде немедленная для изучения; в игре только seam.

Win→loss: `?witch=m06&sequence=F14&speed=normal`, затем fast. В диагностике после двух sample раундов включена явная pause; P продолжает. Проверить, что старое тело заканчивается, новое поле/итог0 не получают старую win-подпись, Spin доступен. Missing frame/decode: `?witch=m06&fault=media`; manifest404: `?witch=m06&fault=manifest`. Round/wallet не должны ждать media.

Для пауз: открыть настройки на движении, дождаться полного входа; clock/frame неподвижны. Закрыть; нет накопившихся реакций. Повторить tab hide/resume и поворот. Reduced Motion → один neutral, оба frame pool освобождены, кадры не переключаются. `?text=large` — доступный стресс-макет с контролируемой прокруткой. Системный text zoom и локализации проверить отдельно на устройстве.

Device gate: реальные iPhone Safari/Android Chrome/desktop Safari по доступности, модель/OS/browser, safe areas, orientation, cold/warm10Mbps/100ms, poster<1s/IDLE<3s, p95 смены поз≤display frame, thermal/memory, 200 переходов и30 минут wall-clock. Непроверенные ячейки — UNAVAILABLE. Desktop narrow viewport и ускоренные30мин active time это не заменяют.

Таблица решения заполняется человеком: IDLE ACCEPTED/REWORK; SMALL_WIN ACCEPTED/REWORK; mobile layout ACCEPTED/REWORK; дата/reviewer/ссылка на запись; конкретные кадры исправления. Автоматического ACCEPTED нет. Следующий ограниченный пакет — правки PO и physical-device QA; остальные три клипа только после решения по эталонам.
